# Security Policy

## Supported Versions

This plugin is developed on a single active line (`beta`). Only the latest published version is supported with security fixes.

## Reporting a Vulnerability

If you find a security vulnerability in this plugin, please **do not open a public GitHub issue**.

Instead, report it privately via [GitHub Security Advisories](https://github.com/NebzHB/homebridge-jeedom/security/advisories/new) for this repository, or by emailing nebz@nebz.be.

Please include as much detail as possible: affected version, steps to reproduce, and potential impact. You should expect an initial response within a few days.
